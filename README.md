# YouTube Sponsor Skip (Jev)

Расширение для Chrome и Safari (macOS), которое само находит рекламные интеграции внутри русскоязычных YouTube-видео и перематывает их.
Речь о той рекламе, которую автор зачитывает в самом ролике: «спонсор этого видео», промокоды, «ссылка в описании».

Решение принимает модель **TypeSafe Jev** (`typesafe/jev-1.13`) через OpenRouter по субтитрам видео. В отличие от
[SponsorBlock](https://sponsor.ajay.app/), разметка не зависит от того, отметил ли кто-то рекламу вручную, поэтому
расширение работает и на небольших русскоязычных каналах.

## Как это работает

1. Вы открываете видео на `youtube.com/watch`. Расширение берёт русские субтитры, ручные или автоматические.
2. Субтитры режутся на куски по 20 секунд. Про каждый кусок Jev отвечает: «реклама» или «контент».
3. Соседние рекламные куски склеиваются в отрезок, а его границы уточняются вторым проходом с шагом ~5 секунд.
4. Когда воспроизведение доходит до отрезка, плеер перематывает его и показывает подсказку
   «Пропущена реклама, 1:03 · **Вернуть**».
5. Результат запоминается: повторный просмотр того же видео бесплатный и мгновенный.

Пока разметка не готова или если что-то пошло не так, видео играет как обычно. Расширение скорее покажет рекламу,
чем перемотает нужный фрагмент.

## Возможности

- Автоматическая перемотка рекламных вставок с кнопкой «Вернуть».
- Окно по клику на значок:
  - сколько вставок найдено;
  - кликабельные таймкоды: переход к началу вставки, чтобы проверить разметку;
  - кнопка «⏸ Пауза / ▶ Продолжить»;
  - сколько потрачено сегодня.
- Подсказка при наведении на значок: статус и таймкоды найденных вставок.
- Дневной лимит расходов: после него новые видео не анализируются.
- Кэш на 500 видео.
- Режим «только предлагать»: вместо автоперемотки показывается кнопка «Пропустить».
- Реклама самого YouTube (ролики до видео и в середине) не трогается: это отдельная задача.

## Точность

Проверено на 6 видео каналов Wylsacom и AcademeG (около 3 часов). Эталон — разметка SponsorBlock, проверенная вручную.

| Метрика | Результат |
|---|---|
| Поймано рекламных секунд | ≈91% |
| Лишняя перемотка, худшее видео | 11 с |
| Ложные срабатывания посреди обычного контента | не было |

Известные слабые места:

- короткая рекламная заставка в первые секунды ролика может быть пропущена;
- граница отрезка может сдвигаться на несколько секунд;
- нативная реклама, вплетённая в сюжет, распознаётся хуже явной;
- выборка небольшая, два канала, поэтому на подкастах и интервью точность может отличаться.

## Стоимость

Расширение использует ваш ключ OpenRouter. Анализ одного видео стоит в среднем **около $0.0025**
(на тестовых роликах длиной 12–54 минуты).

| Просмотр | В день | В месяц |
|---|---|---|
| 5 видео в день | ~$0.013 | ~$0.40 |
| 20 видео в день | ~$0.05 | ~$1.50 |

Платный запрос делается только при открытии нового видео с русскими субтитрами. Главная страница, превью, Shorts,
повторные просмотры и видео из кэша ничего не стоят. Сверху расходы ограничены дневным лимитом (по умолчанию $0.20).

## Установка

Для обоих браузеров нужен ключ OpenRouter: получите его на [openrouter.ai/keys](https://openrouter.ai/keys) и
пополните баланс на пару долларов. Код у версий общий, но настройки, ключ, кэш и дневной лимит у каждого браузера
свои: ключ вводится в каждом отдельно, и лимит считается отдельно.

### Chrome (а также Edge, Brave, Arc)

1. Скачайте `youtube-sponsor-skip-<версия>.zip` со страницы [Releases](https://github.com/AnatoliyLikarchuk/youtube-sponsor-skip/releases)
   и распакуйте. Или клонируйте репозиторий.
2. Откройте `chrome://extensions` и включите **Режим разработчика** (Developer mode) в правом верхнем углу.
3. Нажмите **Загрузить распакованное расширение** (Load unpacked) и выберите папку с `manifest.json`.
4. Откройте параметры расширения: «Сведения» → «Параметры расширения», или пазл на панели → ⋮ → «Параметры».
   Вставьте ключ `sk-or-…` и нажмите «Сохранить».
5. Закрепите значок на панели через пазл → булавка и откройте любое русскоязычное видео с рекламной интеграцией.

После обновления файлов нажмите ⟳ на карточке расширения в `chrome://extensions` и перезагрузите вкладку YouTube.

### Safari (macOS)

Расширение для Safari — это маленькое приложение-контейнер. Оно не подписано сертификатом Apple Developer, поэтому
Safari нужно разрешить неподписанные расширения. Проверено на Safari 27.

**Из релиза:**

1. Скачайте `YouTube-Sponsor-Skip-Safari-<версия>.zip` со страницы
   [Releases](https://github.com/AnatoliyLikarchuk/youtube-sponsor-skip/releases), распакуйте и перенесите
   `YouTube Sponsor Skip.app` в «Программы».
2. Приложение не подписано, поэтому macOS не даст его открыть. Снимите карантин командой ниже и откройте
   приложение один раз:
   ```sh
   xattr -dr com.apple.quarantine "/Applications/YouTube Sponsor Skip.app"
   ```
3. Дальше по шагам из раздела «Включение в Safari».

**Из исходников** (нужен полный Xcode, не только Command Line Tools):

```sh
sh safari/build.sh   # собирает, ставит в /Applications и открывает приложение
```

**Включение в Safari:**

1. Safari → Настройки → **Дополнения** → «Показывать функции для веб-разработчиков».
2. Safari → Настройки → **Разработчик** → «Разрешить неподписанные расширения» (нужен пароль).
3. Safari → Настройки → **Расширения**: включите «YouTube Sponsor Skip (Jev)». Если его нет в списке, прокрутите
   список вниз или откройте `YouTube Sponsor Skip.app` ещё раз.
4. Там же нажмите «Изменить сайты…» и разрешите `www.youtube.com` и `openrouter.ai`. Без `openrouter.ai`
   запросы к Jev не пройдут.
5. Кнопка «Настройки» в карточке расширения: вставьте ключ `sk-or-…` и сохраните.

Safari сбрасывает разрешение на неподписанные расширения при каждом перезапуске, поэтому шаг 2 придётся повторять.
Насовсем это убирает только подпись платным аккаунтом Apple Developer.

После обновления файлов снова запустите `sh safari/build.sh` и перезагрузите вкладку YouTube.

## Значок

| Значок | Что значит |
|---|---|
| `1`, `2`, … | Найдено столько рекламных вставок |
| пусто | Рекламы не найдено или видео ещё не открыто |
| `…` | Идёт анализ |
| `II` | Пауза: новые видео не анализируются, видео из кэша перематываются |
| `CC` | У видео нет русских субтитров |
| `KEY` | Ключ не задан или неверный |
| `$` | Дневной лимит исчерпан |
| `~` | Часть запросов не удалась, результат неполный |
| `!` | Расширение выключено: сменилась версия модели (включить в параметрах) |
| `ERR` | Ошибка анализа |

## Настройки

- **Ключ OpenRouter** хранится локально и показывается только как «задан / не задан».
- **Дневной лимит, $**: по умолчанию 0.20.
- **Порог p(sponsor)**: по умолчанию 0.5. Выше — меньше лишних перемоток, но больше пропущенной рекламы.
- **Перематывать автоматически**: если выключить, вместо перемотки появится кнопка «Пропустить».
- Таблица расходов за 7 дней и кнопка «Очистить кэш».

## Приватность и безопасность

- В OpenRouter уходит **только текст субтитров** открытого видео. История просмотров, другие сайты и содержимое
  экрана никуда не отправляются.
- Ключ хранится в `chrome.storage.local`. Страницы YouTube прочитать его не могут. В Chrome доступ к нему есть
  только у фоновой части расширения. В Safari такого ограничения нет (`setAccessLevel` не поддерживается), поэтому
  ключ технически доступен и контент-скриптам самого расширения.
- Расходы ведутся пессимистично: перед каждым запросом резервируется $0.02, после ответа списывается реальная цена.
  Если исход запроса неизвестен, резерв сохраняется. Автоповторов нет.
- Если в ответе API окажется другая версия модели, расширение выключается до подтверждения: инструкция проверялась
  на конкретной версии.

## Ограничения

- Работают только видео с русскими субтитрами (ручными или автоматическими).
- Только `youtube.com/watch` в Chrome на компьютере и в Safari на Mac. Shorts, встроенные плееры, Safari на
  iPhone/iPad и мобильный YouTube не поддерживаются.
- Субтитры берутся из запроса самого плеера: прямой запрос YouTube отдаёт пустой ответ без токена proof-of-origin.
  Если YouTube изменит плеер, получение субтитров может сломаться.
- Расширение не публикуется в Chrome Web Store и App Store и рассчитано на личное использование.

## Разработка

Без сборки и без npm-зависимостей: чистый JavaScript (ES-модули), Manifest V3. Нужен Node ≥ 18 для тестов.

```sh
node --test          # офлайн-тесты логики, без сети
node eval.mjs        # офлайн-проверка набора для регрессии
node eval.mjs --paid # платная регрессия точности (лимит $0.10), нужен ключ в ../../.env
```

`eval.mjs` использует видео и эталон из соседнего каталога спайка `../youtube-sponsor-spike/`.
Журнал проверок (как получаются субтитры, регрессия, живые тесты) — в [NOTES.md](NOTES.md).

### Структура

| Файл | Назначение |
|---|---|
| `manifest.json` | Описание расширения (MV3) |
| `page-hook.js` | Работает в контексте страницы: находит русскую дорожку и перехватывает ответ `/api/timedtext` плеера |
| `content.js` | Связь страницы и фоновой части, перемотка, тост «Вернуть», переход по таймкоду |
| `background.js` | Фоновая часть: кэш, бюджет, вызов Jev, значок, подсказка, состояние вкладок |
| `popup.html`, `popup.js` | Окно по клику на значок |
| `icons/` | Значки: `icon-*` — оранжевый (список расширений), `toolbar-*` — синий для панели браузера |
| `options.html`, `options.js` | Страница параметров |
| `lib/captions.js`, `lib/chunks.js` | Разбор субтитров json3, нарезка на куски и подкуски |
| `lib/prompt.js`, `lib/jev.js` | Сборка запросов и клиент Decisions API с проверкой ответа |
| `lib/segments.js`, `lib/pipeline.js` | Склейка решений в отрезки, уточнение границ, параллельность до 4 запросов |
| `lib/budget.js`, `lib/ask.js` | Журнал расходов и вызов Jev с резервированием |
| `lib/cache.js`, `lib/store.js`, `lib/settings.js` | Кэш, последовательная запись в хранилище, настройки |
| `lib/gate.js`, `lib/once.js` | Нужен ли анализ видео; защита от двойного анализа |
| `lib/skipper.js`, `lib/summary.js` | Логика перемотки; тексты для окна и подсказки |
| `safari/build.sh` | Сборка Safari-версии: копирует нужные файлы в `safari/ext/`, собирает Xcode-проект, ставит в `/Applications` |
| `safari/YouTube Sponsor Skip/` | Xcode-проект приложения-контейнера для Safari (создан `safari-web-extension-converter`) |
| `eval.mjs` | Регрессия точности на эталонных видео |
| `tests/` | Офлайн-тесты (`node --test`) |
